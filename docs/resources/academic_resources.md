## 📑 重要学术期刊

### 🌍 国际顶尖期刊

- **Impact Factor:** ~4.5
- **Focus:** Physical medicine and rehabilitation
- **Access:** Subscription (some open access)
- **Website:** https://www.archives-pmr.org/

## 🔍 学术数据库

### 1. PubMed ⭐⭐⭐⭐⭐

**网址：** https://pubmed.ncbi.nlm.nih.gov/

**特点：**
- 全球最大的生物医学数据库
- 免费使用
- 提供免费全文（PubMed Central）
- 有中体字幕（部分）

**如何使用？**
1. 输入关键词（如 "stroke rehabilitation"）
2. 使用过滤器（年份、语言、文章类型等）
3. 查看摘要和免费全文
4. 使用 "Related articles" 功能

**适用人群：** 所有康复专业学习者

---

### 2. PubMed Central (PMC) ⭐⭐⭐⭐⭐

**网址：** https://www.ncbi.nlm.nih.gov/pmc/

**特点：**
- 免费全文数据库
- 收录大量高质量期刊
- 可下载PDF
- 有中文字幕（部分）

**如何使用？**
1. 输入关键词
2. 筛选 "Free full text available"
3. 下载PDF阅读
4. 收藏感兴趣的文章

**适用人群：** 希望免费阅读全文的学习者

---

### 3. Web of Science ⭐⭐⭐⭐⭐

**网址：** https://www.webofscience.com/

**特点：**
- 权威引文数据库
- 可查看文章被引情况
- 提供期刊影响因子
- 需要订阅（大多数大学购买）

**如何使用？**
1. 输入关键词
2. 按被引次数排序
3. 查看高被引文章
4. 分析研究趋势

**适用人群：** 有大学图书馆访问权限的学习者

---

### 4. CNKI（知网）⭐⭐⭐⭐

**网址：** https://www.cnki.net/

**特点：**
- 国内最大的中文学术数据库
- 收录大量中文期刊和学位论文
- 需要订阅（大多数国内大学购买）
- 中文资源最全

**如何使用？**
1. 输入中文关键词
2. 筛选年份、作者、机构等
3. 下载全文（PDF或CAJ）
4. 查看引用情况

**适用人群：** 中文学习者，国内大学学生

---

### 5. 万方数据 ⭐⭐⭐⭐

**网址：** https://www.wanfangdata.com.cn/

**特点：**
- 国内重要的中文学术数据库
- 收录大量中文期刊和学位论文
- 需要订阅（大多数国内大学购买）
- 部分资源免费

**如何使用？**
1. 输入中文关键词
2. 筛选年份、作者、机构等
3. 下载全文
4. 查看引用情况

**适用人群：** 中文学习者，国内大学学生

## 🔧 学术搜索工具

### 1. Google Scholar ⭐⭐⭐⭐⭐

**特点：**
- 免费学术搜索
- 覆盖各个学科

**网址：** https://www.researchgate.net/

**特点：**

4. 参与讨论

**适用人群：** 希望与研究者交流的学习者

## 📊 如何高效利用学术资源？

### 1. 制定阅读计划
- 每周阅读1-2篇高质量论文
- 优先选择高被引文章
- 关注最新发表（过去1-2年）

### 2. 做好笔记
- 记录关键发现
- 记录研究方法和局限
- 记录自己的想法

### 3. 批判性思考
- 评估研究质量
- 思考研究局限
- 思考如何应用到实践

### 4. 持续追踪
- 设置关键词提醒
- 关注感兴趣的研究者
- 定期浏览顶刊新文章

## 🎯 科研入门建议

### 零基础学习者
1. **从综述开始**：综述文章总结了一个领域的进展，适合入门
2. **选择高被引文章**：这些文章通常质量较高
3. **配合在线课程**：理论学习要配合论文阅读
4. **加入学术社区**：与同行交流，分享经验

### 有基础学习者
1. **深入研究方向**：选择1-2个方向深入研究
2. **阅读最新论文**：了解前沿进展
3. **尝试复现研究**：加深理解
4. **参与科研项目**：如果有条件，参与导师的科研项目

### 临床康复师
1. **阅读临床指南**：了解循证实践
2. **关注应用研究**：选择与应用相关的基础研究
3. **参与临床研究**：如果有条件，参与临床研究项目
4. **持续更新**：定期阅读新文章，了解前沿进展
