# 📝 康复治疗师资格考试备考指南

> 康复治疗师资格考试是康复专业学生的「毕业考试」，也是进入临床工作的必备证书。
> 
> 本页面提供**完整备考指南**，帮助你高效通过考试。

---

## 📋 考试基本信息

| 项目 | 内容 |
|------|------|
| **考试名称** | 康复医学治疗技术资格考试 |
| **组织单位** | 国家卫生健康委人才交流服务中心 |
| **考试类别** | 全国统一考试（每年一次） |
| **考试形式** | 人机对话（计算机考试） |
| **报名网站** | [www.21wecan.com](https://www.21wecan.com/) |

---

## 🎯 考试科目与题型

| 科目 | 内容 | 题型 |
|------|------|------|
| **基础知识** | 解剖学、生理学、病理学、生物力学等 | 单选题 |
| **相关专业知识** | 临床医学概论、药理学等 | 单选题 |
| **专业知识** | 康复评定、物理治疗、作业治疗、言语治疗等 | 单选题 |
| **专业实践能力** | 案例分析、操作技能 | 案例分析题 |

> 💡 **重要**：考试题型全部为**选择题**（含单选和共用题干题），没有填空题或问答题。

## 📚 推荐备考资料

### 官方教材（必买）

- 📕 **《康复医学治疗技术》考试指导（中级）**：人民卫生出版社
- 📗 **《康复医学治疗技术》练习题集**：人民卫生出版社
- 📘 **《康复医学治疗技术》模拟试卷**：人民卫生出版社

> 💡 建议购买最新版（一般每年更新），因为考试大纲会有调整。

### 免费资源

- 🔗 **人才交流服务中心官网**：提供历年真题样卷（免费下载）
- 🔗 **中国大学 MOOC**：相关课程免费学习，打好基础
- 🔗 **康复医学网**：提供部分免费练习题

## 🗓️ 备考时间安排（建议）

### 阶段一：基础复习（考前 3-4 个月）

- [ ] 通读官方教材《考试指导》，理解每个知识点
- [ ] 配合中国大学 MOOC 相关课程，加深理解
- [ ] 每天学习 1-2 小时，周末可增加到 4-6 小时

### 阶段二：刷题巩固（考前 2 个月）

- [ ] 完成《练习题集》全部题目（至少刷 2 遍）
- [ ] 整理错题本，重点攻克薄弱知识点
- [ ] 每天刷题 1-2 小时

### 阶段三：模拟冲刺（考前 1 个月）

- [ ] 完成《模拟试卷》全部套卷（严格计时）
- [ ] 复习错题本，确保同类题目不再出错
- [ ] 每天模拟考试 1 套，保持手感

## 💡 备考技巧分享

> 💬 **学长学姐说**：

- **重点章节**：康复评定、物理治疗学、作业治疗学是考试重点，占分最多
- **刷题优先**：先刷练习题集，再刷模拟试卷，最后复习错题
- **理解为主**：不要死记硬背，要理解「为什么选这个答案」
- **关注大纲**：每年考试大纲会有微调，注意新增内容
- **机考练习**：提前在官网练习机考系统，熟悉操作界面
