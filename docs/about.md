# 关于本项目

## 项目初心

这个项目诞生于一个简单的想法：

> **"如果CS专业有自学指南，那康复专业为什么不能有？"**

康复医学是一个充满人文关怀的专业，它帮助人们重获健康、回归生活。但相比计算机科学，康复专业的学习资源分散、缺乏系统性的自学路线图。

本项目旨在**填补这一空白**，为所有对康复专业感兴趣的人提供一个**免费、开放、系统性**的自学指南。

---

## 项目愿景

- 📚 **系统性的学习路线** — 从零基础到临床进阶，有路可循
- 🌍 **国内外资源汇总** — 整合中英文学术资源、在线课程、经典教材
- 🔬 **前沿与经典并重** — 既涵盖基础医学核心，也追踪机器人康复、脑机接口等前沿方向
- 🤝 **开源共建** — 任何人都可以贡献内容，让资源越来越完善

---

## 适用人群

| 人群 | 如何使用本指南 |
|------|----------------|
| 🔰 零基础自学爱好者 | 从「零基础入门路径」开始，按部就班 |
| 🎓 康复专业学生 | 参考各课程模块，补充课堂之外的资源 |
| 🔄 其他专业转行者 | 重点学习基础医学+康复核心课程 |
| 🏥 临床康复师 | 直接跳转到进阶方向和临床实践模块 |

---

## 项目结构

```
rehab-self-learning/
├── docs/
│   ├── intro/          # 使用指南
│   ├── roadmap/        # 学习路线图
│   ├── basics/         # 基础医学课程
│   ├── core/           # 康复核心课程
│   ├── clinical/       # 临床实践模块
│   ├── advanced/       # 进阶方向
│   ├── books/          # 好书推荐
│   ├── resources/      # 资源汇总
│   └── certification/  # 考证指南
├── mkdocs.yml          # MkDocs 配置文件
└── README.md
```
