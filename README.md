## 🎯 本项目能帮你什么？

康复治疗学是一个融合医学、生物学、工程学和心理学的交叉学科。无论你是：

- 📚 **零基础自学爱好者**：想要系统学习康复知识，为未来职业发展做准备
- 🎓 **康复专业学生**：希望补充课内未覆盖的优质资源，提前学习感兴趣的方向
- 🔄 **其他专业转行者**：非康复专业想要转行进入康复领域，需要系统学习建立完整的专业基础
- 🏥 **临床康复师**：希望继续深造，学习前沿技术和理论，提升临床实践能力

本指南都将为你提供一条清晰的学习路径。

## 📖 如何使用本指南？

### 🎯 第一步：确定你的学习路径

本指南为不同人群提供了差异化的学习路径：

| 目标人群 | 推荐路径 | 预计时长 |
|---------|---------|----------|
| 零基础爱好者 | [零基础入门路径](docs/roadmap/beginner.md) | 2-3 年 |
| 康复专业学生 | [康复专业学生路径](docs/roadmap/student.md) | 1-2 年（补充学习） |
| 转行者 | [转行者路径](docs/roadmap/career_changer.md) | 1.5-2.5 年 |
| 临床康复师 | [临床康复师进阶路径](docs/roadmap/clinician.md) | 持续学习 |

### 📚 第二步：按照路线图学习

本指南的核心内容分为六大模块：

1. **[基础医学课程](docs/basics/anatomy.md)**：解剖学、生理学、病理学、生物力学等
2. **[康复核心课程](docs/core/rehab_intro.md)**：康复评定、物理治疗、作业治疗、言语治疗等
3. **[临床实践](docs/clinical/orthopedic.md)**：骨科康复、神经康复、心肺康复、运动损伤康复等
4. **[进阶方向](docs/advanced/robotics.md)**：机器人康复、VR/AR康复、脑机接口、康复AI等
5. **[好书推荐](docs/books/chinese_books.md)**：中外经典教材和参考书
6. **[考证指南](docs/certification/therapist.md)**：康复治疗师资格证等职业证书

### 🔍 第三步：利用资源汇总

- **[在线课程平台](docs/resources/online_courses.md)**：中国大学MOOC、Coursera、edX 等
- **[学术资源](docs/resources/academic.md)**：PubMed、知网、康复期刊等
- **[临床指南](docs/resources/clinical_guidelines.md)**：WHO、中国康复医学会等权威指南
- **[社区与论坛](docs/resources/community.md)**：康复从业者交流平台

## 🌟 项目特色

### 1. **系统化的学习路径**

不是零散的资源堆砌，而是提供了完整的学习规划，明确不同模块的学习顺序和重点。

### 2. **高质量的课程资源**

所有推荐资源均来自：

- 🏫 **国内外名校公开课**：哈佛、斯坦福、北京体育大学、上海体育大学、首都医科大学等
- 📚 **经典教材和参考书**：涵盖康复各个领域的中外经典著作
- 🏥 **临床实践指南**：WHO、中国康复医学会等权威机构发布的指南
- 🔬 **前沿科研资源**：顶级期刊论文、学术会议、研究方向

### 3. **实践导向**

推荐的课程大多包含：

- 📝 完整的讲义和课件
- 🔬 实验和实践操作视频
- 📊 病例分析和临床案例
- 🎯 课后习题和自测题

### 4. **中英双语**

提供中文和英文版本的内容，方便不同语言习惯的学习者使用。

### 5. **持续更新**

项目保持活跃维护，不断补充新的优质课程和资源，适配康复领域的最新发展（如机器人康复、VR康复、脑机接口等）。
